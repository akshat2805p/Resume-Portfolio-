## 📌 Overview

A **production-quality personal portfolio** built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, just clean craftsmanship. The site is designed to be cinematic, fast, and classy, featuring full-viewport animations, scroll-triggered reveals, parallax blob backgrounds, interactive 3D card tilts, and animated stat counters.

---

## ✨ Features

### 🎬 Hero Section
- **Full-screen centered layout** with Playfair Display 160px name
- **Animated gradient blobs** — float continuously + respond to mouse parallax
- **Animated stat counters** — Projects Shipped, LeetCode Solved, Rating, Devpost Rank
- **Character-by-character name animation** with glitch-slide effect
- **Vertical animated scroll indicator** at the bottom center
- Social buttons with per-platform color reveals on hover

### 📜 Scroll Animations (Classy & Smooth)
| Class | Effect |
|-------|--------|
| `.reveal` | Fade up from 48px with spring easing |
| `.reveal-left` | Slide in from -56px (left) |
| `.reveal-right` | Slide in from +56px (right) |
| `.reveal-scale` | Scale(0.88) + fade up |
| `.reveal-wipe` | Clip-path left→right wipe |
| `data-stagger` | Auto-staggers all direct children |
| `.section-title` | Clip-path text reveal on scroll enter |
| `.section-label` | Animated gold rule line expands on enter |

### 🛠 Sections
- **About** — Left/right split scroll reveal, IIT Bombay role card, status badge
- **Skills** — Tab switcher (Languages / Frontend / Backend & DB / DevOps / Core Concepts), animated progress bars, tech chip cloud
- **Projects** — 6 featured projects in a staggered 2-column grid with 3D tilt on hover
- **Achievements** — 6 cards in a staggered 3-column grid with scale-in
- **Contact** — Dark section with contact methods + functional form

### ⚡ Interactions
- **Custom cursor** — dot + ring, ring expands on interactive elements
- **3D card tilt** — project cards follow mouse with perspective rotation
- **Marquee speed boost** — ticker speeds up while scrolling, relaxes after
- **Nav shadow** — fades in once past 60px scroll
- **Mouse parallax** — hero blobs move in opposite directions on mouse move
- **Active nav links** — highlight current section while scrolling

## 🏃 Running Locally

No build step needed — it's pure HTML/CSS/JS.

```bash
# Clone the repo
git clone https://github.com/akshat2805p/Resume-Portfolio-.git
cd Resume-Portfolio-

# Open directly in browser
open index.html
# or on Windows:
start index.html
```

Or serve with any static file server:

```bash
npx serve .
# → http://localhost:3000
```
