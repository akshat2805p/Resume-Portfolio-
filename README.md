# Akshat Pandey — Portfolio v2.0 (React + Three.js)

A high-performance developer portfolio built with **React 19**, **Three.js**, **Vite**, and **Lucide Icons**. Designed with a restrained obsidian/graphite dark aesthetic, glowing mint accents, interactive 3D telemetry visualization, and deep case studies.

## 🚀 Key Highlights & Architectural Features

- **Interactive 3D Three.js Background**: Real-time particle constellation with proximity connections, floating geometric wireframes, camera parallax tracking, scroll reactions, and reduced-motion fallbacks.
- **Flagship Project Deep-Dives**: Detailed case study modals for:
  - **eSim KiCad Health Analyzer**: 6 Python/wxPython plugins, KiCad 6–10 API abstraction, 3-stage AI reporting pipeline, and NetworkX dependency graphs.
  - **AIOps Sentinel**: Server telemetry anomaly detection achieving 83.96% precision and 0.6854 F1 score across 10,368 samples with a 6× false alarm reduction.
  - **Mini-Dynamo**: 5-node Go distributed key-value store with consistent hashing (320 tokens), WAL disk durability, vector clocks, hinted handoff, and gossip protocol.
  - **Aura AI**: Manifest V3 Chrome Extension powered by Gemini 2.0 Flash for on-page grounded summarization, contextual Q&A, and snippet management.
- **Searchable & Filterable Repository Manifest**: Complete directory of all 33 public repositories with live real-time search, category filtering (Featured, Projects, Experiments, Forks, Archive), and honest labeling.
- **Interactive Printable Résumé Modal**: Clean, printable CV viewer formatted for one-click printing (`window.print()`) or PDF export (no phone number displayed).
- **Developer CLI Terminal (Easter Egg)**: Floating interactive terminal (accessible via `~` or button) with commands (`help`, `about`, `projects`, `skills`, `fellowship`, `leetcode`, `contact`, `clear`).
- **Theme Synchronization**: Dark & Light mode toggle with local storage persistence.
- **Responsive & Accessible**: Optimized for desktop, tablet, and mobile with keyboard navigation and semantic HTML.

## 💻 Local Development

Clone the repository and install dependencies:

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## 📦 Production Build

```bash
# Compile optimized bundle to dist/
npm run build

# Preview production build locally
npm run preview
```
